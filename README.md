# PCA Utrecht Palimpsest
The code used for the paper on the Utrecht Palimpsest. It has been accepted by Manuscript Studies for publication in the Autumn of 2027, but the author's accepted manuscript can be read here: https://jasperleonorakamermans.com/wp-content/uploads/2026/09/sacramentarium_traiectense_aam.pdf

The corresponding dataset is found here: doi:10.17026/SS/BLKKFY
